# GhostOps Autonomous SRE Assistant

This Python script demonstrates a basic autonomous SRE assistant. It checks the status of a specified systemd service and attempts to restart it if it's not running, simulating an automated recovery process. It also shows a simplified disk space check.

## Language

`python`

## How to Run

Run this script using: python ghostops_assistant.py
Ensure you have 'sudo' privileges to restart services if needed. Replace 'nginx' with a service name present on your system.
